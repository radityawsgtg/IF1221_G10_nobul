# Praktikum IF1221 Logika Komputasional - Permainan Kartu UNI (Kelompok nobul)

## Deskripsi Singkat
Proyek ini adalah implementasi simulasi permainan kartu **UNI** menggunakan paradigma pemrograman deklaratif dengan bahasa Prolog. Proyek ini dikerjakan untuk memenuhi Tugas Besar mata kuliah IF1221 Logika Komputasional. Pada Milestone 1 ini, program sudah dapat memodelkan inisialisasi state permainan, pembagian kartu, dan mekanisme giliran dasar.
